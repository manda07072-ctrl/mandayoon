# 포트원 V2 실결제 확인 서버

이 스크립트는 결제 직전 주문을 `카드결제` 시트에 보관하고, 브라우저의 결과만 믿지 않고 포트원 결제 조회 API에서 실제 승인 상태·금액·Store ID·카드 수단을 확인한 뒤 `결제완료`로 바꿉니다. API Secret은 Apps Script의 Script Properties에만 저장합니다.

## 설치와 배포

1. Google Apps Script에서 새 프로젝트를 만들고 이 폴더의 `Code.gs` 내용을 붙여넣습니다.
2. 프로젝트 설정의 Script Properties에 다음 값을 저장합니다.
   - `PORTONE_API_SECRET`: 포트원 콘솔에서 발급한 **V2 API Secret**
   - `ORDER_SPREADSHEET_ID`: 주문 기록을 저장할 기존 구글 스프레드시트의 ID
   - `ORDER_SHEET_NAME`: `카드결제` (선택; 비우면 기본값 사용)
3. `doGet` 또는 `doPost`를 처음 실행할 때 Google 권한 요청을 승인합니다. 실제 카드 결제는 아직 하지 마세요.
4. 배포 → 새 배포 → 웹 앱을 선택하고 실행 권한을 본인으로, 액세스 권한을 모든 사용자로 설정해 배포합니다. 표시된 `/exec` URL을 복사합니다.
5. 포트원 콘솔의 실연동 채널에서 웹훅을 `결제모듈 V2` / `실연동`으로 설정하고, 같은 `/exec` 주소를 결제 알림 URL로 등록합니다. 코드가 결제 요청에 `noticeUrls`도 포함합니다.
6. `index.html`의 `CARD_LIVE_CONFIG.backendUrl`에 `/exec` URL을 넣어 배포합니다. 이 URL은 공개되어도 되는 주소입니다. API Secret은 여기에 넣지 않습니다.

Apps Script URL을 저장한 뒤 랜딩페이지에서 버튼을 눌렀을 때는 서버 연결 확인과 주문 준비 기록까지만 진행합니다. 채널과 상품 금액을 점검하기 전까지 본인 카드로 실결제하지 마세요. 실결제는 실제 청구를 만들며, 테스트 카드 번호를 사용하지 않습니다.

## 관리 시트

`ORDER_SPREADSHEET_ID`로 지정한 문서에 `카드결제` 탭을 처음 요청할 때 자동 생성합니다. 기존 시트의 열 구조를 바꾸지 않습니다. 각 결제 전에 `결제대기` 행이 만들어지고, 포트원 API 확인에 성공한 경우에만 `결제완료`가 기록됩니다. 취소·실패한 결제는 자동으로 완료 처리되지 않습니다.

현재 Google Drive에 비슷한 이름의 주문관리 문서가 둘 이상 있으므로, 기존 입금 주문을 보고 관리하는 파일의 ID를 넣어야 합니다. 잘못 고르면 카드 주문이 다른 파일에 저장됩니다.
